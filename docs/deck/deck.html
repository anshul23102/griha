31,347
entries on the real UN, US OFAC, EU and UK lists. A match goes to an officer, never an automatic decline

Withhold

Fraud and sanctions findings are hidden from the applicant (KYC Directions paras 19, 20(4), 52). Officers see everything.

New

Video KYC (V-CIP) checklist: a session cannot be completed unless every mandatory element of paras 26 and 27 is on record. Prompting forces rejection.

11Security and scale
Security and scale

Built as if the data were real, and measured, not promised.

Encrypted

AES-256-GCM, one key per case

Private by link

Case key, or staff login; else "not found"

Tamper-evident

Hash-chained audit, replayable

Rights

Erase, access, 72-hour breach register

Hardened input

Strict schemas, XML entities refused, size caps

Clean scans

bandit, pip-audit, pnpm audit in CI

Not claimed: a million decisions a day. Peaks, bureau latency and the database would decide it.

12Honesty
Honesty

What is real, what is simulated, and what is not built.

Real
  • APR and the Annex I statement, EN and HI
  • Four sanctions lists, 31,347 entries
  • Servicing and V-CIP rules
  • AA signing and encryption
  • Hash-chained audit, encryption
  • DPDP rights, breach register
Simulated
  • Bureau, KYC, land records
  • Every applicant and statement
  • The Aggregator: a mock
  • V-CIP video: hashes only
  • Property prices, default outcomes
Not built
  • Live AA and FIU (needs RBI, Sahamati)
  • MHA list, PEP data
  • CKYCR upload (needs CERSAI)
  • V-CIP recording, liveness model
  • India-region hosting

No Indian loan-level data was available, so policy cut-offs are illustrative and the Hindi text awaits a legal translator. For a lender, griha.byod --csv book.csv retrains the same model on its own loan book. Sources for every figure: the Data sources page and README.
